# 模型产物

训练 checkpoint 不进入 BotZone 源码仓库。正式候选模型必须携带：

- `magic`、模型版本、规则契约版本、特征版本；
- 架构维度、量化方式、权重 SHA-256；
- 训练数据/切分/随机种子记录；
- Python 与纯 C++ 前向的 golden parity 报告。

C++ 推理和 ModelPolicy 已接通，当前模型缺失、校验失败或推理失败会明确记录 `rule_fallback`。`policy=model` 只在本次确实由模型评分选出合法动作时输出，并附权重 SHA 摘要；贡还牌和发牌阶段记录 `stage_rules`。

版本化二进制可从平台用户存储读取，也可原样嵌入生成的 C++ 单文件。两条路径共享同一加载检查；嵌入包同样须满足 4 MB 源码上限。训练结果、模型对照、完整对局和平台验证齐备前，不能宣称正式模型已发布。
