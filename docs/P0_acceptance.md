# 核心验收清单

本文件记录门槛；实际报告见 `progress.md`，附件裁判与线上原版必须区分。当前 C++ core
的在线规则变体已按已取得的 BotZone 官方还牌语义实现，但代码级对齐不等于平台验收。

- [x] C++17 独立规则、状态回放、普通 JSON 单行输入输出。
- [x] stdin 不关闭时仍能单行响应并退出，畸形输入明确失败。
- [x] 贡还、双贡、抗贡、空历史、重复 pass、完成玩家和接风状态单测。
- [x] 配子动作生成、小手牌穷举、牌型/大小/贡还的附件裁判差分。
- [x] C++ `RuleVariant::BotzoneCompat` 按官方 `isValidReturn` 边界处理还牌（level 9 上限 8，其它等级上限 9，排除当前级牌），并有定向单测。
- [x] 100 局全等级、0/1/2 贡完整对局；每次请求手牌与附件裁判一致。
- [x] 纯 C++ 推理、模型格式/SHA/维度校验、Python/C++ 特征对齐和合成权重前向对齐。
- [x] 多文件源码合并后本地 C++17 编译通过。
- [x] 10,000 局规则压力验收报告（868,093 决策，非模型压力）。
- [x] 首轮南邮 BC checkpoint、验证选型、测试集一次性评估；候选 v1 牌力未达标。
- [ ] 真实训练模型前向对齐、实际模型决策比例/降级次数、模型完整对局压力。
- [ ] 首发模型与规则基线的同牌换座对照和置信区间；增强晋级采用至少 2,000 副 duplicate。
- [x] 取得官方原版裁判、记录 SHA 并完成初步逐行比对；C++ core 已落实还牌边界定向 golden。
- [x] 最终 anchor 单文件包按官方还牌边界完成 13 等级 golden（零 mismatch）。
- [ ] 在平台环境中复核官方还牌边界，并核对协议字段/阶段语义（本机 golden 不等于平台验收）。
- [ ] BotZone G++ 7.2.0 编译、私有实战、单核时限/内存和正式发布。

没有可验证状态时输出 `response:null` 和错误信息；健康状态中的模型异常才使用合法规则降级。不存在适用于所有未知请求的“安全过牌”。
